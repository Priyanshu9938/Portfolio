# Portfolio website PRD

## Purpose 
create a portfolio website that presents my projects,details,skills and education clearly

## Audience 
Recrutiers and visitor who want to know more about my projects,skills and education. it can aslo be interviewers.

## main goals
- explain the projects i have worked on

## Page Structure & Section Order
The website scaffold must follow this exact sequence:
1. **Details / Hero Header:** Personal identification, headline, location, and executive summary/bio.
2. **Projects:** Dedicated project catalog/showcase presenting real security initiatives, tools, and technical writeups (note: left empty if missing in source profile).
3. **Skills & Certifications:** Top technical competencies, offensive security capabilities, tools (Burp Suite, Nuclei, Python), and official certifications.
4. **Experience & Education:** Professional career timeline (Trainer, Founder, Chapter Leader) and academic qualifications (MCA in AI, BCA).
5. **Contact:** Professional connectivity channels (LinkedIn, verified direct contact methods).

## Functional & Design Requirements
- **Theme:** Liminal Horizon (Monochromatic slate, stone, high typographic contrast).
- **Simplicity & Speed:** Fast-loading, semantic HTML structure, and clean responsive layout without unnecessary animations or heavy frameworks.
- **Content Authenticity:** Strict alignment with verified profile data. No filler or mock data.
